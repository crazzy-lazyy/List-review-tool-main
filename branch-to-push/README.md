# 清单对比与校审工具（ChecklistTool）

> 面向内网办公环境的**离线清单数据校审桌面工具**（PyQt6，Windows）。围绕“清单数据”提供一整套闭环能力：解析表格 → 规则校验 / 合规数据生成 / 设备数据填写 / 清单交叉对比 → 结果报告与导出（PDF/Excel/CSV）。附带员工登录与使用统计，并预留可选 AI 辅助（内网 LLM，OpenAI 兼容接口）。
>
> 当前版本：v2.2（单机离线使用；数据全部保存在本机）。
> v2.2 更新（2026-09）：交叉对比结果统一按**基准清单行序**输出、自动检测并醒目提示**表头差异**、修改行**仅高亮变化的单元格**（界面与 Excel/PDF 导出一致）、结果页中文列名与颜色图例，详见[第一节第 5 小节](#5-交叉对比与结果报告v22-优化)。

## 一、功能总览

### 1. 员工登录与使用统计（启动必经）

- 启动时填写**工号 / 姓名 / 部门**（部门可下拉选择或手输；可勾选记住，下次自动填充）。取消登录即退出程序。
- 登录后按“工号 + 客户端 + 月份”在本机记录功能使用事件（各页停留时长、校验/对比/生成/导入/导出次数与结果摘要等），**仅用于部门使用统计，不含任何清单数据内容**。
- 客户端唯一标识存于 `%LOCALAPPDATA%\ChecklistTool\client.json`——替换或升级程序后仍可复用同一身份统计。
- 可选将记录同步到共享目录（见“系统配置”页），目录结构为 `共享目录\月份\工号\客户端ID.json`，便于部门汇总。

### 2. 八个功能页（按界面从左到右）

| # | 页面 | 作用 |
|---|------|------|
| 1 | **规则校验** | 载入一份清单文件，勾选要应用的规则后执行校验；结果表格高亮违规字段并提示规则名称，状态栏汇总“违规 N 条，未进入验证 M 行”。 |
| 2 | **数据生成** | 根据规则库**生成合规数据**（不包含故意违规）：固定行数随机生成 / 规则分支全覆盖两种模式；可选模板文件提供列结构与示例值；生成结果直接进入“结果报告”页，可导出复用。 |
| 3 | **设备数据** | 在工具内直接填写设备类清单（内嵌 SQLite 数据库，见[第四节](#四设备数据填写与审查)）：编辑即自动保存、按规则**即时审查**、全表校验、Excel 导入/导出、全局模板列。 |
| 4 | **交叉对比** | 基准清单与一份或多份待对比清单逐表对比：按键列匹配，识别新增/删除/修改行，可配置对比列；两份清单的“版本对比”即基准 + 单份待对比实现。结果统一按基准清单行序输出，并自动检测表头差异（见 [1.5](#5-交叉对比与结果报告v22-优化)）。 |
| 5 | **规则库** | 可视化条件树编辑清单校验规则；默认只读，需管理员秘钥解锁。规则保存后自动通知校验/生成/设备数据各页刷新并重校验。 |
| 6 | **结果报告** | 集中预览最近一次校验/对比/生成的结果表格，导出 **PDF（带格式）、Excel（含标记与高亮）、CSV（纯数据）**，导出在后台线程执行；差异结果带颜色图例，内部列显示中文列名，表头差异醒目警示（见 [1.5](#5-交叉对比与结果报告v22-优化)）。 |
| 7 | **AI 配置** | 配置可选 AI 服务（见[第五节](#五可选-ai-辅助)），供“规则库自然语言生成规则”“交叉对比列名语义匹配”等辅助功能使用；编辑需管理员秘钥解锁。 |
| 8 | **系统配置** | 使用记录共享目录同步：配置共享目录（`\\server\share\...`）、启用自动同步或手动“立即同步”，展示本机客户端 ID。 |

### 3. 支持的表格格式与解析

- 支持 **Excel（.xlsx/.xls）、CSV、TSV、Word（.docx）、PDF**（抽取表格）等常见清单格式。
- 支持**多级表头**：自动检测或按配置的表头行数解析，多行表头合并为层级列名（如 `系统|专业`），便于在键列/对比列/规则字段中选择。
- 可按需配置表头行数、跳过顶部行、限制读取行数。
- `.et`（WPS）等格式暂未接入专用解析，列为后续扩展预留。

### 4. 规则引擎

- 规则为递归条件树（`and`/`or` 组合），字段运算符：`eq/ne/gt/ge/lt/le/in/not_in/not_empty/empty/is_num/regex/contains`。
- **蕴含语义**：父节点自身带条件且有子节点时，表示“若父条件命中，则子条件组必须满足”；父条件未命中的行**直接通过并标记为“未进入验证”**，报告与界面会单独提示，避免误判为合规。
- 字符串比较前统一规范化（去空白、大小写归一），数值字段支持数字比较。

### 5. 交叉对比与结果报告（v2.2 优化）

本轮优化聚焦交叉对比的结果可读性（“版本对比”为交叉对比的单文件形态，同源受益），界面显示与 Excel/PDF 导出的行为保持一致：

**① 统一的输出顺序——以基准清单为主**

- 对比结果统一按**基准清单的行序**输出：主体部分按基准清单顺序逐行输出“修改 / 未变 / 删除”（行内容与“源文件行号”均取自基准清单，“删除”行紧随同键的配对行之后）；仅存在于待对比文件的行统一作为“**新增**”追加在结果**末尾**，按待对比文件行序排列（行内容与行号均取自待对比文件）。
- 不论是否勾选“仅对比两表共有键的行”“按行号对齐”等选项，输出的排序基准都保持一致，避免切换选项后结果顺序跳变、难以对照。
- “源文件行号”固定为结果**第一列**；汇总行同步注明各排行号来源：`新增行(待对比行号)`、`删除行(基准行号)`、`修改行(基准行号)`。
- 新增“差异说明”列给出可读的判定原因，例如“该键仅存在于待对比文件（基准清单没有此行）”“该键在基准清单中出现的次数多于待对比（待对比缺失此行）”“待对比文件比基准多出的行（按行号对齐）”；修改行则逐字段列出“列名: 基准值→待对比值”。
- 按行号对齐模式下，修改行的展示内容同样取自基准清单，与按键列匹配模式一致。
- 勾选“**仅对比两表共有键的行**”时，仅存在于单一文件的行（新增/删除）**不会输出**，结果只包含两表共有键的“修改/未变”行；需要查看这些行时请取消勾选。

**② 表头差异自动检测**

- 执行交叉对比时（应用列名映射 / AI 匹配**之后**），自动比较两份文件的表头：识别待对比文件**缺少的列**（基准清单有 → 该列不参与对比）与**多出的列**（基准清单没有 → 同样不参与对比）。
- 结果页汇总行以“**表头差异 N 处！**”前缀醒目提示，并在表格上方以红色逐条列出缺失/多出的列——这些列未参与对比，请检查表头设置，或先用“表头一致性检查 / AI 智能匹配列名 / 手动匹配列名”对齐表头后再对比，避免漏比。

**③ 修改行只高亮变化的单元格（界面与导出一致）**

- 此前“修改”行整行铺浅黄背景，真正的变化字段反而不易辨认；现在**界面、Excel 导出（xlsxwriter / openpyxl 两种引擎）、PDF 导出**统一改为：修改行**仅高亮“变化字段”列出的具体单元格**（浅黄 `#FFFFE0`），“新增”（绿）/“删除”（粉）行仍整行标记。
- 变化字段列表若以字符串形式保存（如从序列化数据恢复），会自动解析后再高亮。

**④ 结果页可读性**

- 内部列在结果页显示中文列名：`源文件行号 / 差异类型 / 变化字段 / 差异说明`；差异类型列显示中文值：`新增 / 删除 / 修改 / 未变`。导出文件仍保留原始列名与英文代码（`__source_row__`、`added/deleted/modified/unchanged`），便于程序化处理。
- 结果表格上方新增**颜色图例**：对比结果标注“新增行 / 删除行 / 修改单元格”的含义及行号、内容来源（展示内容以基准清单为主）；规则校验结果标注“违规单元格 / later 待补充 / 未进入验证”。

## 三、打包与分发（Windows）

打包由 [ChecklistTool new1.0/ChecklistTool.spec](<ChecklistTool new1.0/ChecklistTool.spec>) 定义，[ChecklistTool new1.0/build_exe.ps1](<ChecklistTool new1.0/build_exe.ps1>) 一键完成，一次构建同时产出两种分发形态：

| 产物 | 位置（ChecklistTool new1.0/dist/） | 说明 |
|------|------|------|
| 免安装文件夹（推荐） | `ChecklistTool/` | 启动快；整个文件夹复制到共享盘/压缩包即可分发 |
| 免安装 zip | `ChecklistTool_v2.2_免安装.zip` | 免安装文件夹的压缩包，解压即用 |
| 单文件 exe | `ChecklistTool.exe` | 单文件便于分发，但每次启动需自解压（首次 20~60 秒） |

```powershell
cd "ChecklistTool new1.0"
powershell -ExecutionPolicy Bypass -File .\build_exe.ps1
```

脚本自动完成：创建/复用虚拟环境 → 安装锁定依赖 → 开发态冒烟（`python main.py --smoke-test`）→ PyInstaller 构建两种产物 → 对两个冻结 exe 分别执行 `--smoke-test`（导入全部重型库 + 读写回环验证，含 SQLite 存储层）→ 清理测试数据 → 压缩免安装 zip。构建机需 Python ≥ 3.11（PyInstaller ≥ 6.16 起支持 Python 3.14）。

双击 [ChecklistTool new1.0/启动工具.bat](<ChecklistTool new1.0/启动工具.bat>) 会自动按“免安装文件夹 → 单文件 exe → 开发模式”的优先级启动。

### 部署注意

- **放在可写目录**（桌面、D 盘工具目录、共享盘）：运行数据 `user_data\` 生成在 exe 旁；若程序目录只读，规则库自动回退到 `%USERPROFILE%\清单对比校审工具\rules`。
- **杀软误报**：单文件 exe 较易被 Windows Defender 等误报，内部分发建议优先免安装文件夹；必要时对 `dist\` 加排除或对 exe 做代码签名。
- **PDF 中文渲染**：导出 PDF 时自动注册 Windows 自带黑体/雅黑/宋体（simhei → msyh → simsun 依次尝试），简体中文 Windows 上无需任何配置。
- **版本与图标**：exe 右键属性显示“清单对比与校审工具 v2.2.0.0”；正式发布前请把 [ChecklistTool new1.0/version_info.txt](<ChecklistTool new1.0/version_info.txt>) 中的 CompanyName 占位符替换为公司名称；图标可由 `python tools\make_icon.py` 重新生成（需 requirements-build.txt）。
- **自检旗标**：`ChecklistTool.exe --smoke-test` 执行无界面自检，结果写入 `user_data\logs\smoke_test.log`，退出码 0 为通过（正常使用无需该参数）。

## 四、设备数据（填写与审查）

内置数据库在 `user_data/checklist_db.sqlite`（SQLite，WAL 模式），界面为“设备数据”页：

- **清单管理**：新建（手动列名 / 使用全局模板列 / 从 Excel 导入仅列结构 / 导入列 + 数据）、复制、重命名、删除；表格表头右键可插入 / 重命名 / 删除列（重命名后台批量重写，大表不卡界面）。
- **自动保存**：编辑后约 0.3 秒自动批量写库，无需手动保存；支持 **Ctrl+C / Ctrl+V** 直接与 Excel 互拷（粘贴自动补行）、Del 删除行、表格底部新增行。
- **即时审查**：按顶部“审查规则”下拉（全部规则或某个规则集）对编辑行即时校验：
  - 违规单元格 **红色高亮**，悬浮显示规则名称/说明；
  - 父条件未命中的行 **橙色** 标记“未进入验证”；
  - 尚未保存成功的编辑以浅蓝底色提示；修复违规后高亮自动消失。
- **全表校验**：后台全量校验（带进度），底部明细列表点击自动定位到违规行。
- **全局模板列**：管理员秘钥解锁后在“全局模板列”中维护公共字段，新建清单可一键复用，保证各清单字段规范。
- **导出**：复用结果导出引擎，可带违规高亮导出 xlsx / csv / pdf。
- **限制**：本机单用户使用，同一时间请勿用多个程序实例编辑同一清单；行按填写顺序排列（v2.2 无排序/筛选）；大清单分页加载（每页 2000 行，滚动自动加载）。

## 五、可选 AI 辅助

内置 OpenAI 兼容接口客户端（vLLM、Ollama、LocalAI、DeepSeek 等皆可），仅在需要时启用，未配置时相关功能自动降级、不影响主流程：

- **规则库**：输入自然语言描述，一键生成规则树（如“当系统为给排水时，专业不能为空”）；
- **交叉对比**：待对比文件列名与基准不一致时，可用 AI 做**列名语义匹配**辅助选列。

在“AI 配置”页填写 API 地址 / 密钥 / 模型 / 推理力度 / max_tokens / 超时重试并“测试连接”，保存后全应用生效（保存位置 `user_data/ai_config.json`，密钥仅存本机）；环境变量 `CHECKLISTTOOL_AI_*` 作为初始默认值（见第七节）。提示：thinking 模型建议把推理力度设为“关闭思考”或提高 max_tokens，否则回复可能被思考过程耗尽。

## 八、自检（开发 / 验证）

```bash
python main.py --smoke-test        # 全功能无界面自检，exit code 0 = 通过
python smoke_test_generate.py      # 数据生成引擎专项自检（随机/全覆盖生成零违规）

自检覆盖：各表格格式解析回读、规则引擎语义（含蕴含与未进入验证判定）、对比引擎、生成引擎（按规则自检、分支覆盖）、导出（Excel/CSV/PDF，含 PDF 中文断言）、设备数据 SQLite 存储层回环（建表 / 批量 1000 行 / id 键分页遍历 / 列重命名 re-key / 级联删除 / 重复列拒绝）。打包流程会在两个冻结 exe 上自动再跑一遍。

## 九、项目结构（便于扩展）

```
ChecklistTool/
├── main.py                      # 入口：--smoke-test 分支、日志、高 DPI、登录后拉起主窗口
├── config/                      # 配置与路径（版本、秘钥、AI 默认值、目录常量）
│   └── app_config.py
├── core/                        # 核心逻辑（纯逻辑层，不依赖 Qt）
│   ├── parsers/                 # 表格解析（Excel/CSV/TSV/Word/PDF、多级表头）
│   ├── rules/                   # 规则引擎（条件树、蕴含语义、未进入验证判定）

## 十、限制与 FAQ

- **设备数据为本机单用户**设计；多人并发/实时协同不在 v2.2 范围。规则库亦为本地文件，多机统一规则需自行分发 `rules_db.json`。
- **AI 是可选项**：未配置内网模型时，自然语言建规则、列名语义匹配等功能自动禁用或要求先配置，其余功能不受影响。
- **安全性说明**：秘钥与 AI 密钥以本地文件保存（非加密），设计目标是“防误操作 + 内网使用”，并非强安全方案；使用记录仅统计使用情况，不含清单与设备数据内容。
- **构建产物体积较大**（免安装文件夹约 190 MB，单文件约 84 MB）：主要来自 pandas/PyQt6/reportlab 等运行库；分发请走内网共享盘或压缩包。
- 未覆盖的功能边界：行排序/筛选、多人协同、规则库云同步、`.et` 格式解析（均列为后续扩展方向）。
